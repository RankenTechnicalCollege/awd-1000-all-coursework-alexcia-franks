Common Network Protocols

HTTP (Hypertext Transfer Protocol)
Used for transferring web pages on the internet. It defines how messages are formatted and transmitted.
FTP (File Transfer Protocol)
Used for transferring files between computers on a network. Often used for uploading website files.
TCP (Transmission Control Protocol)
The foundational communication protocol suite for the internet, handling routing and reliable data delivery.
IP (Internet Protocol)
Ensures data is sent to the correct location
